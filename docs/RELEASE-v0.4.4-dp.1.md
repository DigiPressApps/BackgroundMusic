## Highlights / 主な機能

**English**
- Persist per-app volume and pan across app and system restarts
- Automatically restore saved levels when playback starts (e.g. Finder Quick Look previews)
- Route app-volume controls to Safari / Chrome media helper processes (existing DPA fork feature)

**日本語**
- アプリ別音量・パンの永続化（再起動後も反映）
- 再生開始時の自動音量復元（Finder プレビュー等）
- Safari / Chrome 等のメディアヘルパー向けルーティング（DPA Fork 既存機能）

**Details / 詳細:** [CHANGELOG](https://github.com/DigiPressApps/BackgroundMusic/blob/master/docs/CHANGELOG-fork-persistent-app-volumes.md)
